# CRC Safety Loop

This P0 safety scope defines the guardrails required before expanding CRC workflows:

- intended-use boundaries for patient triage, clinician review, and research use
- deterministic clinical safety policy
- mutation replay for safety-critical behavior changes
- persistence traceability for clinical state and events
- harness and release reports that make safety verification repeatable

This scope explicitly excludes the Doctor Review Cockpit, literature evidence, research workspace, and automated learning. Those areas remain out of scope for this P0 loop and must not be treated as delivered safety capabilities here.
