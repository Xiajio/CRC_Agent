# 前端集成测试计划：后端-前端对齐与交互验证

**日期**: 2026-05-13
**目的**: 逐功能验证前端 UI 与后端数据契约的对齐，以及交互流程的完整性
**测试方式**: 启本地服务（`frontend npm run dev:e2e` → `127.0.0.1:4173`），按清单逐项执行

---

## 测试环境准备

### 启动服务
```bash
# 后端服务
cd backend && uvicorn app:app --host 127.0.0.1 --port 8000

# 前端服务（绕过 PowerShell PATH/Path 冲突）
cd frontend && npm run dev:e2e    # → 127.0.0.1:4173
```

### 浏览器检查
1. 打开 `http://127.0.0.1:4173`，确认页面加载无白屏
2. 打开 DevTools → Console，确认无红色错误（允许橙色 warning）
3. 打开 DevTools → Network，准备监控 API 请求

## 执行说明

1. **按顺序执行**，每项通过打 ✓，失败记录原因
2. **有后端依赖的项**需要真实后端服务运行（或 mock）
3. **卡片类测试**（4.x、7.x）需要后端产出对应卡片，可能需要特定的会话上下文
4. **split identity 测试**（11.x）需要患者端先填写身份、医生端绑定患者
5. **数据库/注册表测试**（8.x、9.x）需要后端有数据
