# Learning Job Artifacts

This directory stores append-only LearningJob artifacts for shadow-only review.

Files under `jobs/` and `candidates/` are review material for the Step 13
learning pipeline. They do not apply prompts, rubrics, routes, templates, RAG
content, safety policy, feature flags, or model training data.

Candidate patches remain inert until a separate human-reviewed release process
promotes approved release intent through the normal governance path.
